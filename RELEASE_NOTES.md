# The Tipsy Tail v0.2.8 — The game's own water in the pool

- The pool is now drawn with the game's lake water: the same material, mesh layout and lighting as the map's still water. It darkens with depth, lets the plank floor, the ladder and swimming beavers show through the shallows the way the lake does, and ripples, glints and reflects exactly as the game's water. Nothing is imitated any more; the hand-tuned tint, UV fix and ripple animation of v0.2.5 to v0.2.7 are gone.
- The water shader takes everything from a set of data textures the game fills from its water simulation. The mod feeds it a tiny private copy of those (depth, floor, links between cells, surface heights) describing a still, clean pool of the basin's depth, bound to the pool's renderer only. The map's water simulation, its textures and the shared materials are untouched.
- The pool follows the game's water-visibility toggle (switching to the game's transparent water material like the map does) and the level cut-away, and hides with the surface when the pool runs dry as before.
- Nothing to tune any more. `water.cfg` in the mod folder is still read live: `legacy` brings back the v0.2.7 look for comparison, `log` writes the pool's real mesh, material and shader values to Player.log. The presets (**TipsyTail-v0.2.8-water-presets.zip**) are now the default game water, the legacy ripples and the untouched fountain water. If the game water cannot be set up on a machine, the pool falls back to the legacy look and says why in the log.
- Only `Scripts/TipsyTail.Runtime.dll` and the manifest version changed since v0.2.7. The model, blueprint, wet fur relief, capacity and terrain cleanup on demolition are unchanged.

Install by replacing the old TipsyTail folder with the folder from **TipsyTail-v0.2.8-mod.zip**, including Scripts/TipsyTail.Runtime.dll. Restart Timberborn and reload your save. Multiplayer players need matching versions.

Built against Timberborn 1.1.2.4. Offline checks against the game's own files confirm that every data texture the game's water shader reads is bound by the mod and is a hidden shader global, that the mesh layout (vertex flags, skirt vertices, link channels, height texels, data channel order) matches the game's water shader sources, that the material paths match the game's water mesh configuration, and that the basin depth and surface height match the blueprint and the exported model; 58 further checks cover the generated mesh and data map. **The water appearance has not been verified in game by the author.** This is a prototype prerelease.
