# Credits

The Tipsy Tail is a community mod maintained by [Timbermods](https://github.com/timbermods). Original building geometry and generator scripts were developed with assistance from OpenAI Codex.

Timberborn, the referenced game materials, native animations and construction-base assets belong to Mechanistry. A purchased installation of Timberborn is required. This project is not affiliated with or endorsed by Mechanistry.

The mod uses the native blueprint and Timbermesh formats. Meshes were exported with [Mechanistry's Timbermesh exporter](https://github.com/mechanistry/timbermesh); exporter code is not redistributed here.

The public Blender source contains original geometry with simple placeholder materials. Rebuilding against your installed game can load Mechanistry's example materials locally for previewing. Screenshots on the project page are model renders, not in-game screenshots.

The original project files (the Blender model and generator scripts, the mod's blueprints, localization and runtime code, and the documentation) are released under the [MIT License](LICENSE).
